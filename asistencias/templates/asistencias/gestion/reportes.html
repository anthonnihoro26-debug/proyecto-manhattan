Envío automático cada viernes

Para que sea automático, el viernes se puede ejecutar el comando seguro python manage.py enviar_reportes_viernes desde un Render Cron Job.

Horario recomendado: viernes 18:00 de Lima, equivalente a 23:00 UTC (expresión 0 23 * * 5).

La programación se habilita en Render por separado. No queda activada únicamente por instalar este ZIP. El comando y el botón comparten un control que impide dos envíos generales en la misma semana.
